# ابزار متن‌باز محاسبه مقدار مصالح ConcreteFlow

این یک کتابخانه کوچک **مستقل و متن‌باز با مجوز MIT** برای ضرب دقیق اعشار رشته‌ای است. هیچ کد، تنظیمات، طرح تجاری، هویت مشتری، داده کارخانه، پایگاه‌داده یا اتصال تجهیزات از محصول اصلی ConcreteFlow در این مخزن وجود ندارد.

**وضعیت:** نامزد انتشار نسخه 0.1.0، بدون ادعای استفاده عمومی، پذیرش صنعتی یا وجود کاربران خارجی.

## استفاده

ورودی باید رشته اعشاری باشد؛ برای مثال حجم `"7.25"` مترمکعب و نرخ فرضی `"320.5"` کیلوگرم بر مترمکعب، مقدار `"2323.625"` کیلوگرم را به‌شکل دقیق تولید می‌کند.

```js
import { calculateBatchQuantities } from "./src/index.mjs";

const result = calculateBatchQuantities({
  volumeM3: "7.25",
  materials: [{ id: "sample-powder", ratePerM3: "320.5", unit: "kg/m3" }]
});
console.log(result.materials[0].total); // "2323.625"
```

نمونه‌ها **ساختگی‌اند** و نباید به‌عنوان فرمول واقعی بتن، تنظیم دستگاه، تأیید کیفیت یا مجوز تولید به کار روند.

## آزمون و مرز ایمنی

```bash
npm test
npm run audit:release
```

پشتیبانی فقط از `kg/m3` و `L/m3` است؛ هیچ تبدیل چگالی، گردکردن یا فرمان کنترلی وجود ندارد. اعتبارسنجی فنی، تأیید مسئول کیفیت و ایمنی دستگاه بر عهده سیستم استفاده‌کننده است.

مجوز MIT فقط متعلق به **فایل‌های مستقل همین بسته** است؛ کد اصلی و تجاری ConcreteFlow همچنان خصوصی باقی می‌ماند. عمومی‌کردن بسته تضمین دریافت ChatGPT Pro از برنامه OpenAI نیست.
